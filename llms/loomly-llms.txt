# Loomly

> Loomly is a social media management and brand success platform for planning, creating, approving, scheduling and publishing content across Facebook, Instagram, LinkedIn, TikTok, YouTube, Pinterest, Snapchat, Threads, Bluesky and Google Business Profile, with collaboration and approval workflows, a content library, analytics and a community-management inbox. Loomly was acquired by Bending Spoons on 2 January 2025.

> Generated by API Evangelist from the public Loomly surface on 2026-08-13. Loomly does not publish an llms.txt; https://www.loomly.com/llms.txt returns 404. Method: generated.

## What an agent can and cannot do with Loomly

- Loomly publishes **no public developer API, no API reference, and no machine-readable specification** (no OpenAPI, AsyncAPI, GraphQL SDL, JSON Schema or Postman collection).
- The host `api.loomly.com` **does not exist** (NXDOMAIN). Any base URL of the form `https://api.loomly.com/v1` is wrong; do not call it.
- The only Loomly capability an integrator can reach is the **partner-gated platform API behind the Loomly Zapier app**, entered through an OAuth 2.0 authorization-code flow at `https://app.loomly.com/oauth/authorize`. There is no published token endpoint, scope list, or contract.
- The only **anonymously callable** Loomly endpoint is the read-only status API.
- Loomly ships **no MCP server**, **no A2A agent card**, **no SDKs or CLI**, and **no first-party webhooks**.

## Callable surface

- [Loomly Status API](https://status.loomly.com/api/v1): Public, read-only, unauthenticated JSON. Operated for Loomly by SorryApp on the status.loomly.com subdomain.
  - `GET /api/v1/status` — overall system state.
  - `GET /api/v1/components` — the four service components: Publishing, Analytics, Interactions, Website.
  - `GET /api/v1/notices` — paginated incident and maintenance notices.
  - `GET /api/v1/notices/{id}` — a single notice with impacted components and update history.
  - Pagination: `meta.count`, `meta.total_count`, `links.next`; filtering via `filter[<field>_<predicate>]`.
  - No rate-limit response headers are returned on this surface.
- [SorryApp status API reference](https://api.sorryapp.com/v1): vendor documentation for the endpoint shapes above.
